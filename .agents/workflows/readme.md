# Agent workflows

Workflows are explicit, user-invoked engineering sequences for recurring Orbo tasks.
They orchestrate existing skills, rules, CLI commands, and audits; they do not
replace SPECs or introduce a second command surface.

Available workflows:

- `regression-fix.md`: reproduce, specify, test, repair, and validate a regression.
- `review.md`: review a change against public API, SSR, accessibility, voice, tests, and package contracts.
- `release.md`: prepare and validate a SemVer release without publishing autonomously.
- `harness-improvement.md`: measure and improve the engineering harness without changing product behavior.
